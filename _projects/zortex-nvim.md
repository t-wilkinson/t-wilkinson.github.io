**zortex.nvim** is a custom Neovim plugin designed to enhance the development workflow through better information management.

### Technical Highlights

- **Notification Server**: Includes a dedicated server for handling system and editor notifications.
- **Calendar Integration**: Features syncing capabilities with a personal calendar to manage schedules directly within the editor.
- **System Integration**: Utilizes NixOS modules and systemd services to manage background processes and synchronization tasks.
